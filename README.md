# 💻 Fedora KDE Ricing Setup (VirtualBox)

## 📌 Overview

This project showcases my customized **Fedora KDE Plasma desktop environment** running inside a VirtualBox virtual machine.

The goal was to explore Linux ricing by modifying:

* Desktop appearance
* Panel (taskbar) layout
* Icons and themes
* Widgets and visual effects

---

## 🎥 Demo

Videos of the setup are included in this repository:

* Desktop overview
* Panel customization
* Theme and visual changes

---

## ⚙️ System Details

* **OS:** Fedora Linux 43 (KDE Plasma Desktop)
* **Environment:** VirtualBox VM
* **Desktop Environment:** KDE Plasma

## 🎨 Customizations

### 🧱 Panel (Dock)

* Floating panel enabled
* Centered alignment
* "Fit content" width
* Increased panel height for better visibility
* Icons-only task manager

* Blur enabled
